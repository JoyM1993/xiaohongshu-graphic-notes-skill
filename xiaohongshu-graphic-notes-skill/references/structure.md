# Original carousel structures

Use these as narrative tools, not promises of reach. Write original wording for the actual reader.

| Structure | Page sequence | Best fit |
| --- | --- | --- |
| Small experiment | Invitation → three manageable steps → reflection question | Low-risk practical ideas |
| Question and explanation | Reader's question → clear explanation → limits → next action | Educational notes |
| Observation and options | Concrete observation → two alternatives → trade-offs → choice | Decisions without universal answers |

Each page carries one main idea. Cover titles should accurately describe the content, not exaggerate a result. Prefer short sentences, meaningful line breaks, and breathing space. Keep citations and attribution visible when needed; if a source note will not fit, shorten the page or add a dedicated reference page.

For advice, state the relevant context and limits. Do not turn a fictional example into a real testimonial. Do not copy a creator's catchphrases, signature layouts, or branded assets. The included demo uses a fictional reading corner and makes no factual performance claims.
